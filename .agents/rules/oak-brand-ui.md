# OAK UI rule

Before UI work, read `docs/brand/BRAND_UX_CONTRACT.md`.

- Use semantic design tokens; do not copy hardcoded presentation colors into the app.
- Preserve the Spanish-first product vocabulary and OAK's clear, active, encouraging voice.
- Provide loading, empty, error, disabled, focus, hover and success states.
- Verify keyboard navigation, visible focus, reduced motion, 200% zoom, 320 px width and accessible color pairing.
- Add or update component and visual-regression tests with the implementation.
